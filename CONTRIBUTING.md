# Contributing

This repository begins private and single-maintainer.

Every change must:

1. Stay within the phase authorized by `docs/STATUS.md`.
2. Cite evidence for protocol or architecture claims.
3. Avoid secrets, personal data, and proprietary game material.
4. Add or update tests for executable behavior.
5. Keep the working tree clean at handoff.
6. Record unresolved uncertainty instead of guessing.
