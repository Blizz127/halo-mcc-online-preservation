P0-B1A — Bazzite interactive launch: process topology (default/normal launch)
================================================================================

Method: `ps -ef --forest` snapshots taken while the operator drove the Steam GUI
(Play button pressed -> prerequisite install -> game running -> main menu reached),
plus a read-only listing of module names mapped into the MCC-Win64-Shipping.exe
process (`tr ' ' '\n' < /proc/<pid>/maps | grep -oE '[^/]+\.(exe|dll|so)$' | sort -u`).
No process was attached to, ptraced, patched, or injected into; /proc/<pid>/maps was
only read for its list of mapped file paths, never for memory contents.

Sanitized with tools/inventory/linux/redact_process_evidence.py (derives every
placeholder value from the live environment at run time, so no real path or
account id is ever typed literally into the sanitizing command itself).
